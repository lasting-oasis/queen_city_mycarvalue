Carvalue: what's in the repo

lasting-oasis/Carvalue is a Replit-built React and Express dashboard that reads used-car values from a Google Sheet and ranks them like stocks. One branch (main), one commit.

tap to flip · tilt to shine

What the back of the card needs

Each car has only current_value and previous_value. That's enough for the % pill, but not for a chart. No charting code exists. The word "chart" only shows up in color names.

How it works today

  • Data: one Google Sheet tab, with a row per car. The server caches it for 5 minutes.
  • % change: (current − previous) ÷ previous.
  • Hotness score: 70% from the size of the % move, 30% from the car's value. The hottest car ranks first.
  • Stats bar: average market value, number of cars tracked, and the biggest gainer.
  • Stack: React, TanStack Query, shadcn/Tailwind, Wouter routing, Express, and the googleapis package.
  • Theme: dark/light, Inter + JetBrains Mono, trust-blue accent.

How it fits the garage idea

  • The stock-style card works as a garage card for a user's own car.
  • Saving a monthly value snapshot per car gives the missing history, so each card gets a real line chart.
  • The job that saves the snapshot can also send the monthly value check-up email.
  • The values would come from the Nexus Valuation engine, not a hand-filled sheet.
