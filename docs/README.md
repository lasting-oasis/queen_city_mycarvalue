# MiCar docs

Hand-off material for any session or person working on MiCar. These are copies of the Claude Project docs so they are reachable from a plain clone.

- `micar-monorepo-merge.md`: the verified plan for merging queen_city_mycarvalue, car-dealer-sim and micar-tuner into `lasting-oasis/micar`. The runnable kit is at `../tools/merge-kit/` (its README lists prerequisites: git >= 2.40, `pip install git-filter-repo`, Node 22, corepack).
- `micar-garage-product-spec.md`: the product decisions behind MiCar Garage (brand, cards, grade, Keyholder membership, Octane, lot, simulator, go-to-market).
